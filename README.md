# makefun-news-summary

Entry for the make.fun `news-summary-01` competition: a one-day world news summary of 11 November 2026.

`main.py` copies `summary.txt` to the judge's output file. The summary is written from real, sourced reporting of the day (AP, Reuters, BBC, AFP, CNN, Le Monde, The Hindu, ESPN and others), neutral and ordered by importance.
